# Mike Holman — Portfolio & Design System

A lightweight, content-first personal portfolio website built with design system principles.

## Overview

This repository contains the source code for my personal design portfolio. For over twenty years, I have been designing digital products, television platforms, user interfaces, and interactive experiences used by people around the world.

The site is built with a lightweight frontend architecture using standard web foundations. It prioritises performance, maintainability, readability, and clean visual hierarchy over complex build steps or external dependencies.

## Technical Architecture

* **Stack:** HTML5, CSS3, Vanilla JavaScript
* **Hosting:** GitHub Pages
* **Design Strategy:** Token-driven design system
* **Dependencies:** None (No frameworks, bundlers, React, or CMS)
