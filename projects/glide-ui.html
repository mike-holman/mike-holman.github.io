Glide UI

A configurable television user interface framework designed for satellite, cable and IPTV operators around the world.

Role
Lead UI/UX Designer
Platforms
Set-top box, companion app
Responsibilities
UX, UI, design system, delivery
Deliverables
Framework, components, documentation

Overview

One flexible platform, built to travel.

Glide UI was designed as a reusable television platform that could be deployed across multiple operators and territories. Instead of creating a new interface for every customer, the framework could be configured, branded and scaled to suit each deployment.

Over time, it grew to support different customers, markets, hardware platforms and languages while maintaining a consistent foundation.

The challenge

Make bespoke feel simple.

Operators needed distinctive interfaces, but every deployment had to work within set-top box constraints. Building each one from scratch increased design and engineering effort, and made future maintenance harder.

The framework had to accommodate different brands and regions, scale to future projects, and remain straightforward to use with a remote control.

My role

From early discovery through delivery

  • Gathered customer requirements and produced work estimates
  • Created wireframes, prototypes and high-fidelity visual designs
  • Produced UX documentation, feature specifications and optimised assets
  • Created Java layouts and supported engineering and testing

Approach

A predictable experience, with room to adapt.

01

Start with the structure

Each project began with a sitemap and navigation framework. Establishing the structure early helped expose dead ends and simplify the user journey.

02

Design for the remote

A panel-based interaction model revealed content progressively from left to right. Keeping focus visually centred made navigation easier to follow.

03

Keep hierarchy consistent

Main Menu, Primary Panel, Secondary Panel and Tertiary Panel formed a repeatable structure across the product.

The panel model

One navigation language, from menu to detail.

The same left-to-right hierarchy carried users from the top-level menu into increasingly specific choices.

Design system

A system teams could use and extend.

The framework needed more than reusable screens. It needed clear guidance for the people designing, building and adapting each deployment.

Colour & recognition

Dedicated colours helped distinguish sections and reinforce hierarchy. The system was captured in a 44-page styling guide for internal teams and customers.

Typography & language

Montserrat Light was selected for television readability across HD and SD. Character support was expanded manually, informing later Arabic language work.

Reusable components

The component library covered dialogues, player controls, buttons, prompt text, keyboards, loading states and volume handling.

Assets & documentation

A large icon and asset library supported accessibility, regionalisation, broadcast features, system settings and user controls. Eighteen specification documents supported implementation, testing and client review.

Key features

Designed around real platform constraints.

Panel-based navigation

ChallengeLarge television interfaces can be difficult to explore with a remote.

Design responseA left-to-right panel structure progressively disclosed information.

OutcomePeople could move deeper into content and retain a sense of where they were.

Internationalisation

ChallengeThe platform needed to work across different languages and regions.

Design responseFlexible layouts, localisation support and right-to-left considerations were built into the framework.

OutcomeThe interface supported deployments across multiple international markets.

GUI Generator integration

ChallengeImplementing and maintaining screens directly in code took time.

Design responseGUI Generator let designers construct screens visually while updating Java code automatically.

OutcomeThe workflow improved collaboration between design and engineering.

Impact

A reusable foundation for operators worldwide.

The platform was deployed across multiple operators and territories, and also became a sales and marketing demonstration tool for prospective customers.

Philippines

Cignal

We rolled out a unified interface across Cignal's new HD and Hybrid set-top boxes, delivering a consistent viewing experience for the Filipino pay TV market.

United States

AFN

AFN delivers television and radio programming to U.S. service members stationed overseas. This rollout brought the Glide UI and eight new HD video channels to their hardware lineup.

Mexico

Dish

A tailored interface designed for one of the country's leading pay TV providers, blending satellite and free-to-air terrestrial channels into a seamless viewing experience.

Afghanistan

ABS / Oqaab

Afghanistan's national DTT service. Although the project was cancelled near completion, it provided valuable experience in designing complex right-to-left (RTL) user interfaces.

Looking back

What I took forward.

Component-based thinking, reusable patterns and strong documentation were central to making the platform scalable. The work also brought real challenges: adapting to television hardware, supporting multiple languages and RTL layouts, and balancing consistency with each operator’s brand.

If I revisited the project today, I would expand accessibility support, formalise the design system further, increase usability testing and explore more responsive experiences across devices.
